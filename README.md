# Coin Flip Simulator

A virtual coin toss application.

## Features

- Random heads or tails
- Result statistics
- Reset option

## How to Use

Click Flip Coin to simulate a toss.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Flip the coin multiple times and record the results.
- [ ] Verify that Heads plus Tails equals total flips.
- [ ] Reset the statistics and check all totals return to zero.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
